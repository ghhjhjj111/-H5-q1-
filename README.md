# 兼职招聘小程序零工招聘H5网站小程序求职兼职招聘小程序同城兼职招聘小程序

源码地址：ym7k.com/19239/

这套同城零工兼职招聘系统面向本地灵活用工市场，覆盖家政、水电工、月嫂、搬家、管道疏通、代驾、家电维修、同城跑腿、家教等本地服务工种，支持微信小程序、H5 双端部署，适合搭建县城、本地同城兼职、临时工对接平台。

### 招工方功能

- 发布零工岗位，自由设置薪资模式：月薪、按件计费、按小时、按天结算，可选日结、周结、月结
- 填写岗位要求、工作详情、工作地址，自动定位同城岗位
- 岗位详情页支持生成海报，方便转发引流；可直接预留联系电话，支持一键拨号
- 管理发布岗位，查看求职者报名记录，在线聊天对接工人
- 付费置顶岗位，提升曝光，快速匹配合适工人

### 求职者功能

- 首页分类直达对应工种：水电、月嫂、家政、搬家、跑腿、家教等
- 按【最新、附近、日结、周结、月结】筛选岗位，优先查看家门口活源
- 订阅零工，有符合条件的新岗位自动通知
- 查看岗位完整详情、地址、薪资、招工要求，一键报名，电话直连用工方
- 用工大厅浏览招聘需求，发布个人求职信息，等待雇主邀约

✅ 丰富工种分类：家政服务、水电维修、月嫂保姆、搬家、管道疏通、代驾、家电维修、同城跑腿、家教
